1,000 Trilingual Math Formulas E-Book (Tamil | English | Sinhala)

An interactive, student-friendly web-based e-book containing 1,000 essential mathematics formulas available in Tamil, English, and Sinhala**.
 How It Was Built
Data Collection & Structuring: Researched and compiled 1,000 math formulas using Microsoft Excel.
CSV Integration: Converted the structured Excel dataset into a clean CSV format and connected it dynamically to the web interface.
Interactive Frontend: Built with HTML to provide a fast, lightweight, and easy-to-read digital book experience.

 Key Features
Trilingual Support: Switch seamlessly between Tamil, English, and Sinhala with a single click.
Easy to Study: Clean layout designed for quick reference and exam preparation.
1,000+ Formulas: Covers a wide range of mathematical topics in one place.
